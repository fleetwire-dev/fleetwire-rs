# fleetwire (한국어 요약)

Tesla Fleet API 를 **읽기만** 하는 비공식 Rust 클라이언트입니다. 어느 호출에 돈이 드는지 타입으로
알고 있습니다. 전체 설명은 [영문 README](README.md)에 있습니다.

> Tesla, Inc. 와 무관한 비공식 프로젝트입니다.

## 왜 만들었나

Fleet API 는 종량제이고, 보통의 HTTP 클라이언트처럼 쓰면 손해가 커집니다.

- `vehicle_data` 는 요청당 $0.002 이고, 잠든 차가 돌려주는 408 도 셈에 들어갑니다(성공한 호출과
  같은 차량별 한도 한 칸을 쓰는 것을 실측했습니다). 시간 초과에 재시도하는 클라이언트는 아무것도
  얻지 못하고 두 번 냅니다.
- 토큰은 bearer 토큰이라, 토큰을 받은 호스트는 사용자처럼 행동할 수 있습니다.
- 토큰을 갱신하면 스코프가 넓어질 수 있습니다. 읽기만 되는 줄 알았던 토큰이 차 문을 열 수 있게
  됩니다.

그래서 이 크레이트는 「하지 않는 것」 다섯 가지를 코드로 강제하고, 가드를 빼면 실패하는 시험으로
고정합니다.

| 하지 않는 것 | 강제하는 방법 |
|---|---|
| Fleet API 에 GET 말고 다른 요청 보내기 | 엔드포인트 trait 를 봉인(sealed)했고, 요청을 보내는 함수는 비공개이며 GET 만 만듭니다. clippy 금지 목록이 뒤를 받칩니다. |
| 유료 요청을 두 번 보내기 | 요청 타입마다 `Pricing` 이 붙습니다. 재시도는 기본으로 꺼져 있고, 401·412 복구는 토큰과 리전만 고치고 유료 요청을 다시 보내지 않습니다. |
| 잠든 차에 돈 쓰기 | `Client::send_guarded` 가 무료 호출로 차 상태를 먼저 보고, 깨어 있을 때만 유료 호출을 합니다. |
| 읽기보다 큰 권한을 가진 토큰 쓰기 | 명령 스코프가 든 토큰은 아무것도 보내기 전에 거절합니다. 서명을 검증하지 않고 읽는 사전 검사라, 읽을 수 없는 토큰은 막지 않습니다(최종 판단은 서버가 합니다). |
| 예상하지 않은 호스트로 토큰 보내기 | 리전 주소는 https·기본 포트·허용 목록의 호스트일 때만 받아들입니다. 리다이렉트는 따르지 않고 환경 변수 프록시는 무시합니다. |

오류 메시지와 본문 미리 보기에서는 토큰·VIN·좌표를 한 곳(`redaction`)에서 가립니다.

## Tesla 계정 없이 돌려 보기

```sh
git clone https://github.com/fleetwire-dev/fleetwire-rs && cd fleetwire-rs
cargo run --example pricing_table   # 엔드포인트 16개 중 어느 것이 유료인지
cargo run --example offline_demo    # 위 다섯 가지 중 넷을 가짜 서버로 직접 확인(장면 8개, 주장 23개)
```

계정이 있으면 [빠른 시작](crates/fleetwire/README.md#quick-start) 세 단계로 차 목록을 받습니다.
이 호출은 무료이고 차를 깨우지 않습니다.

## 숫자 (2026-11-20 기준)

| | |
|---|---|
| 엔드포인트 | GET 16개(차량 12, 사용자 4), 2개가 유료입니다. 실제 응답을 본 곳만 타입을 정하고 나머지는 JSON 그대로 둡니다 |
| 시험 | 단위 시험 419개(`fleetwire` 410, `fleetwire-testkit` 9), README 예제는 문서 시험으로 컴파일합니다 |
| CI | stable·beta·MSRV 1.89, clippy 경고 0, cargo deny, gitleaks, 자가 시험이 있는 불변식 게이트 |
| 실행 방식 | 동기(`ureq` + rustls), 비동기 런타임 없음 |
| `unsafe` | 워크스페이스 전체에서 금지 |

## 어디서 나온 코드인가

이 크레이트는 2026-07-29 부터 개발해 온 비공개 워크스페이스의 읽기 클라이언트입니다. 그 워크스페이스는
차 한 대를 따라가는 서버에서 돌고, 텔레메트리 수신기·원격 MCP 서버·알림 발송기와 「차에 명령을
보낼 수 있는 유일한 크레이트」를 함께 가집니다. 2026-11-20 기준 크레이트 13개, Rust 약 28만 5천 줄,
시험 약 6,100개, 커밋 1,561개, 운영 배포 태그 186개, 커밋 훅과 완료 검사가 돌리는 불변식 게이트 67개입니다.

한 가정의 위치 자료를 중심으로 만든 것이라 대부분은 비공개로 둡니다. 대신 두 가지를 공개합니다.

- [docs/safety-boundaries.md](docs/safety-boundaries.md): 그 시스템이 경계를 지키는 방법입니다.
  명령은 허용 목록이 있는 크레이트 하나에서만, 유료 호출은 보내기 전에 예산 장부에 예약, 공유 파일마다
  쓰는 곳 하나, 좌표는 알림과 도구 답에 나가지 않습니다.
- 이 저장소는 내보내기 스크립트 한 길로만 코드를 받습니다. 개인정보 검사에 한 줄이라도 걸리면
  아무것도 쓰지 않습니다. 그래서 이 저장소의 커밋 이력이 짧습니다.

## 어떻게 만드나

워크스페이스는 [Claude Code](https://claude.com/claude-code)를 구현자로 써서 만듭니다. 병합이 아닌
커밋의 93%가 Claude 공동 작성입니다. 사람은 명세와 합격 기준을 쓰고, 되돌릴 수 없는 일을 결정하고,
결과를 실제 차로 판정합니다. 에이전트를 믿음이 아니라 구조로 묶습니다. 커밋을 막는 게이트, 편집을
멈추는 훅, 지난 결함으로 채점하는 검토자 에이전트, 「가드를 빼면 실패하는 것을 본 시험만 시험으로
친다」는 규칙이 그 구조입니다.

방법과 수치, 이 크레이트에서 실제로 잡은 결함은 [docs/how-this-is-built.md](docs/how-this-is-built.md)에
있습니다. 설계는 [docs/architecture.md](docs/architecture.md)를 보십시오.
