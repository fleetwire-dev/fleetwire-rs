# Security Policy

## Supported versions
This project is pre-1.0 and under active development; only the latest
published version (once published) receives security fixes.

## Reporting a vulnerability
Please report vulnerabilities **privately** via GitHub Private Vulnerability
Reporting: <https://github.com/fleetwire-dev/fleetwire-rs/security/advisories/new>
(enabled once this repository is public). Expect an acknowledgement within a
few days.

**Do not** include real access tokens, refresh tokens, full VINs, GPS
coordinates, account IDs, raw request headers, or unredacted traces in a
report — a security report must not itself leak secrets or PII.
